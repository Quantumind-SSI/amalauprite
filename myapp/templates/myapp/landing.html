Customer Journey

Table QR → /menu/// → filter available items → add to cart → checkout → order appears on staff dashboard instantly. Table number persists in session for seamless flow.

Staff Journey: Register → Login → /management/ → Create items → Generate QR → View orders → Update status → Track revenue.
